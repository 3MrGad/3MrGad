## About

Penetration tester based in **Cairo, Egypt**, focused on **web application, API, and mobile (Android/iOS)** security, with hands-on **manual source-code review**. I hunt bug bounties on **[Bugcrowd](https://bugcrowd.com/h/3Mr)** and HackerOne, where I've reported access-control (IDOR/BOLA), stored and DOM-based XSS, and business-logic issues in large production platforms. ## What I work on

- **Web & API:** OWASP Top 10 & API Top 10, broken access control (IDOR/BOLA), authentication & session flaws, business logic, XSS (stored / DOM / postMessage), SQLi, SSRF, JWT/OAuth, GraphQL.
- **Mobile:** Android & iOS static and dynamic analysis, OWASP MASTG, Frida, Objection, MobSF, jadx, SSL-pinning bypass.
- **Source-code review:** manual white-box review across PHP, JavaScript/Node.js, Python and Java, tracing user input to dangerous sinks.
- **Network & AD:** scanning, enumeration and exploitation with Nmap, BloodHound, Impacket, NetExec, Responder.

Selected bug bounty work (anonymised per program disclosure rules): a cross-user **stored XSS** in a cloud engineering platform; a **DOM-based XSS** in a payment checkout via an insecure `postMessage` → `eval()` handler; two **IDOR/BOLA** flaws in a large retailer's API; and a **password-reset token exposure** acknowledged by the PUBG security team.
